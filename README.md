Download the Windows setup installer or the macOS DMG matching your processor from [Releases](https://github.com/webapp-software/signapp-pad-releases/releases).

Automatic updates are supported by updater-enabled Windows setup installations and signed macOS installations. Updates download in the background and install when the app next launches. The tray menu also offers an update check and restart action. Windows portable builds require manual replacement.

The first updater-enabled version must be installed manually. Clinic configuration is preserved when updating.

This repository contains distribution files only. Application source is maintained privately.
